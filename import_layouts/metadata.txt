name=Import Layouts from Project
qgisMinimumVersion=3.22
qgisMaximumVersion=4.99
supportsQt6=True
description=Import all or selected print layouts (and reports) from another .qgs/.qgz project into the current project.
about=Pick a .qgs or .qgz project, choose one or more of its layouts and import them into the current project.
    Layer references (map layer sets, legends, atlas coverage layers, attribute tables, expressions) are
    remapped to the layers of the current project: by layer ID when it matches, otherwise by layer name,
    and finally by data source. The proposed mapping can be reviewed and overridden before importing.
    The source project is only parsed, its layers are never loaded.
    Available from the Plugins menu and from the Layout menu of the layout designer.
